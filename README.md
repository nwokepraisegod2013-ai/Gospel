# Gospel Stream

A polished Gospel multimedia platform built with Flutter for web, Android, iOS, Windows, and Linux.

## Features

- Video streaming with likes and live chat
- Music playback support
- Books and devotional content
- Live session discovery and join flow
- Creator studio for uploading video, audio, and book content
- Professional glassmorphism UI with a calm single-tone background
- Responsive layout for desktop, mobile, and web

## Getting Started

1. Install Flutter: https://flutter.dev/docs/get-started/install
2. Open the project root in your terminal.
3. Run:
   ```bash
   flutter pub get
   flutter run
   ```

## Notes

This project contains a production-ready frontend shell. For a complete production app, integrate backend services for authentication, streaming delivery, file uploads, and real-time chat.
