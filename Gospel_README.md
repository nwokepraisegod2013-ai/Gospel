# Gospel Stream

A polished cross-platform Gospel streaming experience built with Flutter.

## Features

- Video, music, and book discovery
- Live streaming section with real-time chat support
- Video detail pages with likes and chat feed
- Creator dashboard for uploading audio, video, and PDF content
- Professional minimal glassmorphism UI with a single-tone background
- Responsive design for web, mobile, and desktop

## Run

1. Install Flutter SDK: https://flutter.dev/docs/get-started/install
2. From project root:
   ```bash
   flutter pub get
   flutter run
   ```

## Notes

This repository includes the core app shell and state architecture. Backend integration, authentication, and realtime streaming services can be added using Firebase, Supabase, or your custom backend.
